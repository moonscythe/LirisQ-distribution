# LirisQ Beta bootstrap

This directory is only for LirisQ installations that still use the pre-GitHub
Beta updater. Replace the live `updates/apply.php` and `updates/channel.php`
with the matching files in this directory once. Afterwards sign in as the
streamer, choose **Beta** in Software Updates, then use the ordinary **Check
for Updates** and **Install Update** actions. The updater then verifies and
downloads the release archive from this repository's `beta` branch.

No manifest or release ZIP should be uploaded to the hosted private update
directory for Beta releases.
