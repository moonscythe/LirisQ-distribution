# LirisQ Beta bootstrap

This directory is only for LirisQ installations that still use the pre-GitHub
Beta updater. Replace the live `updates/apply.php` with `apply.php` from this
directory once, while signed in as the streamer. Afterwards choose **Beta** in
Software Updates and use the ordinary **Check for Updates** and **Install
Update** actions. The updater then verifies and downloads the release archive
from this repository's `beta` branch.

No manifest or release ZIP should be uploaded to the hosted private update
directory for Beta releases.
